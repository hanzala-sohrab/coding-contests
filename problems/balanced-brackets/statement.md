A bracket sequence over `()[]{}` is **balanced** if every opening bracket is closed by a bracket of the same type, in the correct order.

For each of `t` strings, decide whether it is balanced.

## Input

The first line contains `t` (1 ≤ t ≤ 10⁵). Each of the next `t` lines contains a non-empty string of the characters `()[]{}`.

The total length of all strings is at most 10⁶.

## Output

For each string, print `YES` if it is balanced and `NO` otherwise.
